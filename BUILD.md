# 🛠️ Building & Running Breakpoint

This guide will help you set up **Breakpoint** locally for development or contribution.

## 📋 Prerequisites
*   Node.js (v18 or higher)
*   npm (v9+ recommended, with workspaces support)
*   **OpenAI API Key** (for test generation & failure analysis)

## 📦 Installation
The project is a **Monorepo** managed by NPM Workspaces.

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-org/ai-test-engineer.git
    cd ai-test-engineer
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # This installs dependencies for root, CLI, Server, and Web UI.
    ```

3.  **Set up Environment**:
    Create a `.env` file at the project root based on the example (or trust the init command later).
    Required variables:
    ```env
    OPENAI_API_KEY=sk-proj-...
    BREAKPOINT_API_KEY=pk_random_string (Generated by server or Init command)
    BREAKPOINT_SERVER_URL=http://localhost:4000
    ```

## 🚀 Running Locally

### 1. **Start the Backend Server** (Required for Reporting)
The server handles API Key validation, project management, and report storage. It uses SQLite by default.

```bash
# From project root:
npm run dev -w @breakpoint/server
# Automatically seeds BREAKPOINT_API_KEY from .env on startup!
```
The server will start on **http://localhost:4000**.

### 2. **Run the Dashboard (Web UI)** (Optional but Recommended)
See the test results visually.

```bash
# In a new terminal:
npm run dev -w @breakpoint/dashboard
```
Open **http://localhost:3000** (or 3001 if port busy).

### 3. **Use the CLI** (The Testing Agent)
You can run the CLI directly from source (via `ts-node` or built `dist`).

**Build First (Recommended):**
```bash
npm run build -w packages/cli
# Or build everything:
npm run build
```

**Initialize Configuration:**
```bash
# Initialize integration with your local server
node packages/cli/dist/index.js init
# Follow the prompts. It will update your .env file automatically.
```

**Run Tests:**
```bash
# Generate and execute tests against the target Server URL
node packages/cli/dist/index.js run
```
The CLI will:
1.  Read your codebase (via `-p` or current dir).
2.  Identify API endpoints.
3.  Generate test cases using AI.
4.  Execute them against the running server (`BREAKPOINT_SERVER_URL`).
5.  Analyze failures and upload reports.

## 🧪 Testing the Tool Itself
To run the internal unit tests for the packages:

```bash
npm test
```

## 🤝 Contribution Workflow
1.  Make changes in the relevant package (`packages/cli`, `packages/server`, `packages/web-ui`).
2.  Run `npm run build` to ensure types are correct.
3.  Run `npm test` to verify logic.
4.  Submit a PR!
